# 前端交互逻辑（v1.7.5）

本文档描述软件全部页面与交互流程，与代码现状一致。更新代码交互逻辑时须同步本文档。

---

## 一、整体框架

### 入口与三层分支（App.tsx）

```
index.tsx（HashRouter） → App.tsx 按优先级分支：
  1) hash 为 #/lock        → LockScreen 锁屏页（独立窗口，最小权限 preload）
  2) 首次引导未完成        → Welcome 引导页（全新库才触发，老用户跳过）
  3) 其余                  → Layout 主布局 + 13 个路由页面
```

### 导航（Layout 侧栏）

资产结构 / 资产管理 / 投资管理 / AI 助手 / 记账 / 债务债权 / 报表分析 / 设置

### 路由表（13 页 + 锁屏）

| 路由 | 页面 |
|------|------|
| / | Dashboard 资产结构 |
| /accounts | Accounts 资产管理 |
| /accounts/:id | AccountDetail 账户详情 |
| /wallet/:type | WalletFlow 钱包流水 |
| /insurance | Insurance 保险 |
| /investments | Investments 投资管理 |
| /investments/:id | HoldingsDetail 持仓详情 |
| /ai | AIAssistant |
| /bookkeeping | Bookkeeping 记账 |
| /social | SocialObligations 债务债权 |
| /reports | Reports 报表分析 |
| /settings | Settings 设置 |
| /lock | LockScreen 锁屏（独立渲染） |
| （无路由） | Welcome 首次引导 |

全部页面路由级 lazy 分包（除 LockScreen/Welcome 静态引入）。

### 全局 hooks

- `useCurrencyRefresh`：订阅主进程 `currency:updated` 事件自动重载数据（已挂 Dashboard/Accounts/Investments 三页）
- `useIdleLock`：主窗口内无输入超过设定分钟（默认 10，可调 1~60）自动调用 `auth:lock` 锁屏（挂 Layout）

## 二、页面交互

### 1. 资产结构 Dashboard
- 7 张统计卡：总资产 / 现金及存款 / 券商流动金 / 投资市值 / 债权 / 债务 / 本月收支
- 资产分布饼图：点击扇区下钻到该分类明细，点击中心区域返回总览
- 资产概览面板：逐行显示各分类金额，点击可展开子项；末行「💎 总资产」
- 资产查询与分析：搜索框（名称/代码）+ 类型/市场下拉筛选 + 排序下拉（市值/盈亏/收益率），下方快速统计条（总数/市值/定存/盈利亏损/最佳最差）
- 总资产走势图（最近 30 天快照）与月度预算进度卡
- 数据加载：mount 拉取一次；`currency:updated` 事件到达自动重载（保证与其它页一致）

### 2. 资产管理 Accounts
- 四层卡片：总资产统计卡 + 各资产大类卡片；银行组卡片可展开（子卡 + 内嵌券商）
- **银行组子项分流（v1.7.5）**：银行卡（💳）点击进 `/accounts/:id`、✏️ 账户编辑；内嵌券商（📈 + 「· 投资」标识）点击进 `/investments/:id`、✏️ 投资账号编辑弹窗；券商流动金子项同券商
- 「+ 添加资产」：先选类型（银行卡/券商账户）→ 对应表单（银行卡：银行名/别名/卡号/币种/余额；券商：名称/券商/币种/账号/关联银行）
- 账户卡片 ✏️ → AccountEditModal（编辑 + 安全删除提示 + 强制删除二级确认与影响清单）
- 债权/债务卡片 → 点击进债务债权页

### 3. 账户详情 AccountDetail
- 存取记录：存入/取出表单（取出可选「转入投资账户」下拉）；编辑带券商联动的记录时出现「同步调整券商流动金」复选框（取消则脱钩）；删除弹窗明示将同步扣回券商流动金
- 定期存款：创建（资金处理方式询问：扣款写记录 / 仅记录）；编辑金额/币种变化弹「同步调整余额并写记录 / 仅改记录（转纯记录型）」；删除弹「退回并写记录 / 仅删除记录」；到期出现「💰 到期处理」（回款金额默认本金+利息可改 + 回款账户）
- 银行理财产品列表与盈亏

### 4. 投资管理 Investments
- 券商账户卡片：名称/券商/持仓数/盈亏 + 市值/流动金；点击进持仓详情
- 添加券商（「无关联」银行时 funding_account_id 归一化 null）；编辑/删除（删除有影响确认）
- 现金管理：存入/取出弹窗（金额校验 >0）
- 「未归属持仓」卡片：孤儿持仓转挂到券商 / 删除
- 今日交易统计与交易列表

### 5. 持仓详情 HoldingsDetail
- 持仓信息卡（数量/成本/现价/市值/盈亏）+ 交易记录列表
- 买入/卖出交易弹窗（数量×价格±手续费，自动重算成本与券商现金流水）
- 编辑/删除交易（自动反向重算；反转不写价格历史）
- 手动改价 ✏️（`asset:updatePrice`，记录价格历史）

### 6. 钱包 WalletFlow
- 余额/收支统计 + 流水列表（limit 200）
- 存入/取出表单（防重复提交 saving 态）
- CSV 账单批量导入（逐条写存取记录+记账+同步余额，失败行报告）

### 7. 保险 Insurance
- 保单列表（类型/年保费/现金价值/到期日）+ 年度保费/现金价值统计卡
- 添加/编辑/删除保单（删除有确认，保费记录保留）
- 缴纳保费：金额/币种/日期 + 付款账户下拉（选账户=自动扣款并写存取记录+记账支出；「不指定」=仅记录）；保单现金价值同步增加

### 8. 记账 Bookkeeping
- 收入/支出列表（limit 100）+ 月度统计
- 添加/编辑/删除记账（类型/金额/币种/分类/账户/日期/描述/标签）；选账户时同步余额
- CSV 批量导入（逐条写入，静默跳过失败行——v1.8.0 计划改为批量+失败明细）

### 9. 债务债权 SocialObligations
- 两个 Tab：债务（我欠）/ 债权（欠我）+ 未结笔数与合计（CNY 等值）
- 添加/编辑（对象/事项/金额/币种/备注/完成日期）
- 「✅ 完成」弹完成日期选择（默认今天、可改）；「🔄 重开」自动清空完成日期；卡片显示「完成于 X」
- 删除直接执行（无确认——v1.8.0 计划补确认）
- 未结债权计入资产、未结债务冲减净资产（联动到资产结构/资产管理/净值）

### 10. 报表分析 Reports
- 图表：月度趋势 / 分类构成 / 资产表现 / 年度已实现盈亏（年份切换）
- 每日交易报表：选日期 → 统计 + 明细 + 导出 Excel
- 资产汇总导出：一键导出 8 个 sheet（总览/银行/钱包/券商/持仓/定存/保险/债务债权），总览含债权债务行

### 11. AI 助手 AIAssistant
- 对话列表 + 输入框 + 快捷提问；SSE 流式渲染（Markdown 先转义后转换）
- 未配置 API Key 时引导去设置

### 12. 设置 Settings
- 应用名称；🔒 启动密码锁卡片（见下）；数据源更新（手动刷新汇率/价格/全部）；货币汇率列表与修改；预算；AI 配置（接口地址强制公网 HTTPS）；数据备份/恢复（选择文件→预览→确认导入，敏感键自动排除）；归档（目录+保留月数+执行）；自定义日结单格式；危险区（清空全部数据：主进程二次确认）
- **启动密码锁（SecurityCard）**：未启用时「恢复邮箱 → 发送测试邮件（官方内置发件，零配置）→ 设密码启用」，SMTP 自定义收进「高级」折叠；启用后：修改密码 / 关闭（需密码）/ 空闲锁定时长（1~60）/ 🔒 立即锁定

### 13. 锁屏 LockScreen（独立窗口）
- 输入密码解锁（错 5 次锁 30 秒）→ 主进程关锁屏窗、开主窗
- 忘记密码三步：输入恢复邮箱 → 6 位验证码（10 分钟有效/60 秒限发/5 次试错）→ 设新密码直接进入
- 「退出应用」直接退出

### 14. 首次引导 Welcome（仅全新库）
- 第 1 步欢迎页 → 第 2 步安全设置（恢复邮箱 → 官方邮箱测试 → 设密码）→ 进入主界面
- 任一步可「跳过，稍后再说」；完成后写入 onboarding.done，不再出现

## 三、全局交互机制

### IPC 调用链
```
渲染端 invoke(channel, ...args)
  → preload 白名单校验（161 频道）
  → 主进程 zod 入参校验（handleValidated）
  → 全局密码锁门禁（未解锁拒绝非 auth 频道）
  → 业务 handler → 返回
```

### 主进程 → 渲染端事件
| 事件 | 用途 | 订阅方 |
|------|------|--------|
| `currency:updated` | 汇率更新完成 | Dashboard / Accounts / Investments（自动重载） |
| `update:status` | 自动更新进度 | UpdateCard |
| `ai:streamChunk/ai:streamDone` | AI 流式响应 | AIAssistant |

### 联动询问式（资产间调整必须用户确认）
- 定存：创建扣款（自动写记录）、编辑差额、删除退回、到期回款——全部弹窗询问
- 存取记录：取出转券商（下拉选择即确认）；编辑券商联动（复选框）；删除明示联动
- 保费：选账户即扣款、不指定仅记录（下拉即询问）

### 表单与反馈模式
- 金额/日期统一组件与解析（parseAmount 千分位/括号/货币符号；normalizeDate 多格式）
- 金额显示：Amount（正负着色）/ NetAmount（净值）/ PctAmount（百分比）
- 错误提示：页面内联红字；部分页面使用 saving 态防重复提交（v1.8.0 计划全站补齐）

### 数据刷新模式
- 页面挂载拉取一次；写操作成功后调用 load() 重载本页
- 汇率更新靠事件推送给 3 个页面；其余页面（Reports/持仓详情等）暂不自动刷新（列入 v1.8.0）

## 四、已知交互缺口（v1.8.0 规划）

- 命令面板与全局快捷键（无）
- 表格无虚拟滚动/表头排序/键盘导航
- 部分写操作静默失败（无提示）、部分表单无防重复提交
- 图表每次数据变化重建实例（闪烁）
- 首页无智能洞察条；加载态为纯文字
- Modal 无焦点管理；窄窗口无响应式
- 人情债删除无确认、记账 CSV 导入静默跳行
