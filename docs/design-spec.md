# 设计规范 — 个人理财投资软件

## 设计原则

- **简洁**：减少视觉噪音，聚焦核心信息
- **直观**：信息层级清晰，操作符合直觉
- **一致**：相同元素使用相同的样式和行为
- **可读**：字号、对比度确保财务数据的清晰可读

## 组件规范

### 按钮（Button）

| 变体 | 样式 |
|------|------|
| `primary` | `primary-500` 底色，白色文字 |
| `secondary` | 白底，`primary-500` 边框和文字 |
| `danger` | `danger` 底色，白色文字 |
| 大小 | `sm`（32px）/ 默认（40px） |
| 加载态 | 文字变为 `⏳ xxx中...`，按钮禁用 |

### 输入框（Input）

- 边框 `--color-border`，聚焦时 `--color-primary-500`
- 高度 `40px`
- 圆角 `--radius-sm`
- placeholder 颜色 `--color-text-muted`

### 卡片（Card）

- 白底，`--radius-md` 圆角，`--shadow-sm` 阴影
- 标题 + 内容结构
- 内边距 `--spacing-lg`
- 页面上卡片间距 `--spacing-lg`

### 表格（Table）

- 表头背景 `--color-bg-secondary`
- 行悬停背景 `--color-primary-50`
- 金额列右对齐，使用数字字体
- 空数据显示 "暂无数据"

### 模态框（Modal）

- 居中弹出，`--shadow-lg` 阴影
- 半透明黑色遮罩（`rgba(0,0,0,0.45)`）
- 标题 + 内容 + 操作按钮区
- 点击遮罩可关闭

### 金额显示（Amount / NetAmount）

- `Amount`：正值 `--color-success`（前缀 `+`）、负值 `--color-danger`（前缀 `-`）、币种符号在前
- `NetAmount`：始终白色/默认色，用于汇总展示
- 保留两位小数，使用 `--font-family-number`

### 进度条（ProgressBar）

颜色根据百分比自适应：

| 范围 | 颜色 | 含义 |
|------|------|------|
| 0–60% | `--color-success`（绿） | 安全 |
| 60–80% | `--color-primary`（蓝） | 正常 |
| 80–100% | `--color-warning`（橙） | 预警 |
| >100% | `--color-danger`（红） | 超支 |

### 标签徽章（Badge）

- 圆角小标签
- 支持颜色变体：success / danger / warning / info / default

### 统计卡片（Dashboard stat cards）

- 大数字（`--font-size-xxl`）+ 标签文字
- 四列网格布局（`grid-template-columns: repeat(4, 1fr)`）
- 响应式：窄屏自动变两列

### 滚动条

- **宽度**：14px（宽轨道，便于拖拽）
- **轨道**：`--color-bg-secondary` 背景 + `--color-border` 细边框
- **滑块**：`#B0B8C1` 深灰，hover 时 `#889098`，active 时 `#667080`，圆角 7px，最小高度 40px
- **箭头按钮**：上下各一个（`single-button`），18px 高，内联 SVG ▲▼ 三角图标
- **双按钮**：显式隐藏（`double-button { display: none }`），确保简洁
- **设计参考**：VS Code 滚动条风格

## 样式方法论

- **BEM 命名**：组件级使用 BEM（Block__Element--Modifier）
  - 如：`.budget-card__alert--warning`、`.stat-card__label`、`.filter-toolbar`
- **CSS 文件**：每个页面/组件对应一个 CSS 文件
- **设计令牌**：所有颜色/字体/间距使用 CSS 变量，禁止硬编码
- **禁止行内样式**：除动态计算值（如 `width: ${percent}%`）外
