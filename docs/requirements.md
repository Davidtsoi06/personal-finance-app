# 需求文档 — 个人理财投资软件

## 项目背景

用户希望开发一款 Windows 桌面应用，核心功能参考"财小蜜"App，以投资管理为重点，统一管理全部个人资产，支持多币种，提供智能记账和财务分析。

## 目标用户

个人使用，财务结构包含多种资产类型（股票、基金、黄金、加密货币等）和多币种账户。

## 功能需求

### 已实现 ✅ ｜ 待开发 ⏳ ｜ 计划中 🔵

### F1. 仪表盘首页 ✅

- 总资产 / 净资产 / 现金存款 / 投资市值 四大统计卡片
- 资产分布饼图（ECharts，按大类聚合）
- 账户概览面板
- 净资产走势图（30 天可配置）
- 月度预算进度卡片（含「剩余每天可用」计算）
- 最近交易记录

### F2. 账户管理 ✅

- 支持账户类型：现金、储蓄卡、信用卡、在线支付（微信/支付宝）
- 添加 / 编辑 / 删除账户
- 账户列表 + 详情页（含存取记录、余额变动历史）
- 显示每个账户的余额和币种

### F3. 投资管理 ✅（核心模块）

- 支持资产类型：股票（A 股 / 港股 / 美股）、基金、ETF、黄金、加密货币、定期存款
- 持仓列表（名称、代码、数量、成本价、当前价、市值、盈亏）
- 手动添加持仓（表单 + 投资账户关联）
- 价格自动更新（新浪 / 雅虎 / 天天基金等数据源）
- 盈亏计算（加权平均成本法，金额 + 百分比）
- 持仓详情页（交易历史列表）
- 买卖交易记录（`trade:record` 自动更新持仓数据）
- **日结单导入** ✅
  - 支持 CSV / Excel 格式
  - 内置富途/国信等主流券商格式
  - 智能关键词匹配 + 自定义格式配置
  - 含分拆/分红等公司行动处理

### F4. 记账功能 ✅

- 收入 / 支出记录（金额、分类、日期、账户、描述）
- 两级分类系统
- 手动逐笔记录
- 月度收支统计

### F5. 多币种与汇率 ✅

- 主要货币：人民币（本位币）、港币、美元
- 扩展货币：欧元、日元、英镑
- 汇率自动更新（exchangerate-api.com）
- 手动修改汇率
- 汇率历史图表

### F6. 报表分析 ✅

- 月度收支趋势图
- 分类消费排行（饼图）
- 年度收支统计
- 持仓表现排行

### F7. AI 投资助手 ✅（新增）

- 基于 DeepSeek API（OpenAI 兼容协议）
- **零成本使用**：注册即送 $5 额度 + 每日 50 次免费调用
- 自动读取用户全部持仓、账户、交易、收支数据作为 AI 上下文
- 流式响应，Markdown 渲染
- 5 个快捷提问模板（分析组合、风险评估、优化建议、投资报告、消费分析）
- API Key 仅存本地主进程，永不暴露给渲染进程
- 新手引导页（注册 → 配置 API Key）

### F8. 数据备份与恢复 ✅（新增）

- **一键导出**：14 张表全部数据 → 单个 Excel 文件
- **一键恢复**：读取 Excel → 预览数据量 → 确认 → 事务导入
- 文件名：`财务数据备份_YYYY-MM-DD.xlsx`
- 适合换设备/重装系统迁移

### F9. 数据归档 ✅（新增）

- 设定数据保留期限（6/12/18/24/36 个月）
- 预设归档文件夹（一次设置，后续自动使用）
- **每月生成一份 Excel 投资统计表**：
  - Sheet 1：月度汇总（交易次数、金额、净现金流出、新增/清仓列表）
  - Sheet 2：交易明细（每笔交易完整信息）
  - Sheet 3：个股统计（按股票聚合的买卖统计）
  - Sheet 4：收支流水（当月记账数据）
- 文件名：`投资统计_YYYY-MM.xlsx`
- 归档完成后自动清理对应月份的数据库记录

### F10. 预算管理 ✅（新增）

- 月度预算设置 + 自定义预警比例
- 仪表盘预算进度卡片：
  - 进度条颜色自适应（绿→蓝→橙→红）
  - "剩余每天可用 ¥XX.XX"（借鉴财小蜜设计）
  - 三种状态：正常 / 预警 / 超支
- 超支弹出 Windows 系统通知

### F11. 智能提醒 ✅（新增）

- 涨跌幅提醒（可独立开关 + 自定义阈值）
- 价格每 30 分钟自动刷新后检查
- 触发时弹出 Windows 系统通知（Electron Notification API）
- 默认：跌幅 5% 开启，涨幅 10% 关闭

### F12. 自动更新 ✅（新增）

- 基于 electron-updater + GitHub Releases
- 启动时自动检查更新
- 下载进度显示
- 一键安装重启

### F13. 日结单自定义格式 ✅（新增）

- 支持用户自定义券商日结单列映射
- 关键词自动匹配
- 管理界面（添加/删除）

- 利息计算
- 还款提醒

## 非功能需求

### N1. 性能 ✅
- 启动速度 < 3 秒
- 页面切换流畅无卡顿

### N2. 界面 ✅
- 简洁直观的布局
- 淡蓝色主色调（`#5B9BD5` / `#4A90D9`）
- 侧边栏 + 内容区布局
- 支持 1280 × 720 及以上分辨率

### N3. 数据 ✅
- 本地存储，无需云端
- SQLite 数据库（better-sqlite3 + WAL 模式）
- 支持数据导入导出（Excel 全量备份）
- 数据库本地加密存储（后续可选 SQLCipher）

### N4. 货币 ✅
- 默认本位币：人民币（CNY）
- 主要外币：港币（HKD）、美元（USD）
- 扩展货币：欧元（EUR）、日元（JPY）、英镑（GBP）
- 汇率自动更新 + 手动修正

### N5. 安全 ✅
- Context Isolation 启用
- AI API Key 仅存主进程，渲染进程不可见
- 导出数据不包含敏感密钥
