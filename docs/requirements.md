# 需求文档 — 个人理财投资软件

## 项目背景

用户希望开发一款 Windows 桌面应用，核心功能参考"财小蜜"App，以投资管理为重点，统一管理全部个人资产，支持多币种，提供智能记账和财务分析。

## 目标用户

个人使用，财务结构包含多种资产类型（股票、基金、黄金、加密货币等）和多币种账户。
