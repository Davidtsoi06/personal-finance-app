# 需求文档 — 个人理财投资软件

## 项目背景

用户希望开发一款 Windows 桌面应用，核心功能参考"财小蜜"App，以投资管理为重点，统一管理全部个人资产，支持多币种，提供智能记账和财务分析。

## 目标用户

个人使用，财务结构包含多种资产类型（股票、基金、黄金、加密货币等）和多币种账户。

### F1. 仪表盘首页 ✅（v1.4.0 增强）

- 总资产 / 现金存款 / 投资市值 / 本月收支 四大统计卡片
- 资产分布 ECharts 饼图，支持**两级下钻**（大类 → 账户明细，点击中心返回）
- 资产概览面板（基于 `account:allAssetsSummary` 预聚合数据，按类别分项显示金额和数量）
- 🔍 **资产查询与分析**（v1.4.0 新增）：搜索/筛选/排序 + 快速统计 + 结果表格
- 净资产走势图（30 天可配置）
- 月度预算进度卡片（含「剩余每天可用」计算）

### F2. 账户管理 ✅（v1.5.0 四层架构重构）

- **四层资产架构**（v1.5.0）：
  - 第一层：总资产仪表盘（全局财富概览）
  - 第二层：大类卡片（微信/支付宝/现金/保险/银行分组/券商）
  - 第三层：子账户明细（多币种余额/定期存款/银行理财产品）
  - 第四层：底层资产（银行持仓/券商持仓 + 交易历史）
- 支持资产大类（`asset_type`）：银行、现金、电子钱包、保险、投资、自定义
- 支持支付方式（`type`）：现金、银行卡、在线支付
- 银行账户按 `bank_name` 自动分组，支持展开/折叠
- 卡片别名（`display_alias`）+ 卡号加密存储（仅显示后 4 位）
- 多币种余额（`account_balances` 表，v7）
- 添加 / 编辑 / 删除账户（含安全删除 + 强制级联删除）
- 资产首页 Layer 2 卡片布局 + 统计卡片
- **电子钱包系统账户**（微信/支付宝/现金，v1.5.0 自动创建）
- 投资账户可**关联银行账户**（v1.4.0）
- 银行日结单导入（CSV/Excel，自定义格式）
- **存取记录编辑/删除**（v1.4.1）：支持修改和删除存取记录，自动回滚余额

### F3. 投资管理 ✅（核心模块，v1.4.0 增强）

- 支持资产类型：股票（A 股 / 港股 / 美股）、基金、ETF、黄金、加密货币、定期存款
- 持仓列表（名称、代码、数量、成本价、当前价、市值、盈亏）
- 手动添加持仓（表单 + 投资账户关联）
- **编辑 / 删除单个持仓**（v1.4.0 新增，v1.4.1 全字段可编辑）
- **交易记录编辑/删除**（v1.4.1 新增）：支持修改和删除买卖交易记录，自动重算持仓成本
- **价格自动更新增强**（v1.4.0 重写）：
  - 智能市场检测（根据代码格式自动判断 A 股/港股/美股）
  - 主/备双数据源架构（5 个市场各配备用源）
  - 主源失败自动 failover + 详细日志（来源、耗时）
- 盈亏计算（加权平均成本法，金额 + 百分比）
- 持仓详情页（交易历史列表）
- 买卖交易记录（`trade:record` 自动更新持仓数据）
- **券商日结单导入**：支持 CSV / Excel，内置富途/国信等主流券商格式，智能关键词匹配 + 自定义格式配置，含分拆/分红等公司行动处理

### F4. 记账功能 ✅

- 收入 / 支出记录（金额、分类、日期、账户、描述）
- 两级分类系统
- 手动逐笔记录
- 月度收支统计

### F5. 多币种与汇率 ✅

- 主要货币：人民币（本位币）、港币、美元
- 扩展货币：欧元、日元、英镑
- 汇率自动更新（exchangerate-api.com，每 6 小时）

- 汇率历史图表

### F6. 报表分析 ✅

- 月度收支趋势图
- 分类消费排行（饼图）
- 年度收支统计
- 持仓表现排行（市值/盈亏排序、总汇总行）
- **每日交易报表**（v1.5.2）：任选日期查看当日交易，买入/卖出笔数金额、已实现盈亏统计，一键导出当日 Excel（汇总 + 明细双 sheet）
- **每日收盘通知**（v1.5.2）：交易日 16:35 自动检查，当日有交易时推送 Windows 通知
- **完整资产汇总导出**（v1.5.2）：7 个 sheet 快照（总览 · 银行账户 · 电子钱包 · 券商账户 · 投资持仓 · 定期存款 · 保险）
- **统一持仓排序**（v1.5.2）：全部列表/报表按 港股→A股→美股→ETF→基金→黄金→加密货币 分组，组内按代码升序

### F7. AI 投资助手 ✅

- 基于 DeepSeek API（OpenAI 兼容协议）
- **零成本使用**：注册即送 $5 额度 + 每日 50 次免费调用
- 自动读取用户全部持仓、账户、交易、收支数据作为 AI 上下文
- 流式响应，Markdown 渲染
- 5 个快捷提问模板（分析组合、风险评估、优化建议、投资报告、消费分析）
- API Key 仅存本地主进程，永不暴露给渲染进程
- 新手引导页（注册 → 配置 API Key）

### F8. 数据备份与恢复 ✅

- **一键导出**：14+ 张表全部数据 → 单个 Excel 文件
- **一键恢复**：读取 Excel → 预览数据量 → 确认 → 事务导入
- 文件名：`财务数据备份_YYYY-MM-DD.xlsx`
- 适合换设备/重装系统迁移

### F9. 数据归档 ✅

- 设定数据保留期限（6/12/18/24/36 个月）
- 预设归档文件夹（一次设置，后续自动使用）
- **每月生成一份 Excel 投资统计表**：
  - Sheet 1：月度汇总（交易次数、金额、净现金流出、新增/清仓列表）
  - Sheet 2：交易明细（每笔交易完整信息）
  - Sheet 3：个股统计（按股票聚合的买卖统计）
  - Sheet 4：收支流水（当月记账数据）
- 文件名：`投资统计_YYYY-MM.xlsx`
- 归档完成后自动清理对应月份的数据库记录

## 非功能需求

### N1. 性能 ✅
- 启动速度 < 3 秒
- 页面切换流畅无卡顿

### N2. 界面 ✅
- 简洁直观的布局
- 淡蓝色主色调（`#5B9BD5` / `#4A90D9`）
- 侧边栏 + 内容区布局
- 支持 1280 × 720 及以上分辨率

### N3. 数据 ✅
- 本地存储，无需云端
- SQLite 数据库（better-sqlite3 + WAL 模式）
- 支持数据导入导出（Excel 全量备份）
- 数据库本地加密存储（后续可选 SQLCipher）

### N4. 货币 ✅
- 默认本位币：人民币（CNY）
- 主要外币：港币（HKD）、美元（USD）
- 扩展货币：欧元（EUR）、日元（JPY）、英镑（GBP）
- 汇率自动更新 + 手动修正

### N5. 安全 ✅
- Context Isolation 启用
- AI API Key 仅存主进程，渲染进程不可见
- 导出数据不包含敏感密钥
