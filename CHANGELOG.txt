🆕 新增功能

1. 滚动条增强（仿 VS Code 风格）
   - 14px 宽轨道，浅灰色背景，始终可见
   - 滑块悬停时颜色加深，拖拽手感更好
   - 上下各一个箭头按钮（▲▼），点击可逐行滚动

2. 自定义格式支持编辑
   - 券商/银行日结单格式新增"编辑"按钮
   - 点击自动填入当前数据，修改后保存即可
   - 位置：设置页 → 数据管理 → 自定义格式

3. 持仓全字段可编辑
   - 代码、类型、市场、货币全部改为可编辑
   - 类型/市场/货币改为下拉框选择，操作更便捷
   - 位置：持仓详情页 → 点击持仓 → 编辑

4. CSV 文件导入支持
   - 券商/银行日结单导入支持 .csv 格式
   - 文件对话框可同时选择 Excel 和 CSV 文件
   - 自动识别格式，无需手动选择文件类型

5. 交易记录编辑/删除
   - 投资交易记录：支持编辑和删除，自动重算持仓成本
   - 存取记录：支持编辑和删除，自动回滚账户余额
   - 位置：持仓详情页 / 账户详情页 → 操作列

6. 子账户管理
   - 在已有银行账户下添加子账户（银行卡/子账户）
   - 无需在创建账户时预设
   - 位置：账户管理页 → 银行账户行 → "➕ 子账户"

7. 强制删除账户
   - 提供安全删除和强制删除两种方式
   - 强制删除自动清理全部关联记录（子账户/存取/记账）
   - 位置：账户管理页 → 删除按钮
