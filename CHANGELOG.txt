个人理财投资软件 v1.4.2 更新说明（2026-08-10）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🆕 新增功能

1. 滚动条增强（仿 VS Code 风格）
   - 14px 宽轨道，浅灰色背景，始终可见
   - 滑块悬停时颜色加深，拖拽手感更好
   - 上下各一个箭头按钮（▲▼），点击可逐行滚动

2. 自定义格式支持编辑
   - 券商/银行日结单格式新增"编辑"按钮
   - 点击自动填入当前数据，修改后保存即可
   - 位置：设置页 → 数据管理 → 自定义格式

3. 持仓全字段可编辑
   - 代码、类型、市场、货币全部改为可编辑
   - 类型/市场/货币改为下拉框选择，操作更便捷
   - 位置：持仓详情页 → 点击持仓 → 编辑

4. CSV 文件导入支持
   - 券商/银行日结单导入支持 .csv 格式
   - 文件对话框可同时选择 Excel 和 CSV 文件
   - 自动识别格式，无需手动选择文件类型

5. 交易记录编辑/删除
   - 投资交易记录：支持编辑和删除，自动重算持仓成本
   - 存取记录：支持编辑和删除，自动回滚账户余额
   - 位置：持仓详情页 / 账户详情页 → 操作列

6. 子账户管理
   - 在已有银行账户下添加子账户（银行卡/子账户）
   - 无需在创建账户时预设
   - 位置：账户管理页 → 银行账户行 → "➕ 子账户"

7. 强制删除账户
   - 提供安全删除和强制删除两种方式
   - 强制删除自动清理全部关联记录（子账户/存取/记账）
   - 位置：账户管理页 → 删除按钮

🐛 问题修复

8. 修复上海 ETF 价格无法获取的问题
   - 以 5 开头的代码（如 515880 通信ETF国泰）无法更新现价
   - 原因：交易所前缀映射遗漏了上海 ETF 代码段

9. 修复银行账户图标显示错误
   - 有子账户的银行账户错误显示 📁 文件夹图标
   - 修复后始终显示正确的账户类型图标（🏦/💵/🔒 等）

10. 数据一致性加固（架构审查修复）
   - 买卖交易、记账、存取记录等关键写入路径新增事务保护
   - 中途崩溃自动回滚，避免数据不一致
   - 账户强制删除新增异常保护

11. 其他修复
   - 修正预警阈值设为 0 时误判为关闭的问题
   - 修正 AI 日报生成时发送重复系统提示的问题
   - 修正持仓更新缺少投资账户关联字段
   - 修正基准货币查询空值崩溃风险
   - 为 ledger:update / asset:update 新增输入数据标准化
   - 侧边栏版本号更新为 v1.4.1
   - Dashboard 代码清理（移除死代码）
