### 第 5 阶段：数据源接入 ✅
- **汇率自动获取**（src/main/services/exchange-rate-fetcher.ts）
  - exchangerate-api.com 免费 API
  - 启动时自动更新 5 种货币汇率
  - 支持单币种查询备用方案
- **价格获取服务**（src/main/services/price-fetcher.ts）
  - A股 → 新浪财经 API
  - 港股 → 新浪港股 API
  - 美股 → Yahoo Finance API
  - 黄金 → 新浪贵金属（自动换算 CNY/克）
  - 加密货币 → CoinGecko API（自动换算 CNY）
  - 请求间隔限速（200ms）防止被封
- **定时调度器**（src/main/services/scheduler.ts）
  - 汇率每 6 小时自动更新
  - 价格每 30 分钟自动更新
  - 支持手动触发全部更新
- **设置页面** 新增数据源刷新面板
  - 3 个按钮：更新汇率 / 更新价格 / 全部更新
  - 实时显示更新状态（成功/失败/计数）
  - 自动更新提示
- **运行时验证**：启动时成功从 API 获取并更新 5 种货币汇率
