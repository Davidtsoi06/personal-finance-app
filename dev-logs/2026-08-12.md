# 2026-08-12 开发日志

## 完成事项

### v1.5.0 四层资产架构重构

1. **数据库迁移 v12**
   - 新增 `insurance_policies` 表（保单管理）
   - 新增 `premium_payments` 表（保费记录）
   - `accounts` 表新增 `display_alias` 字段
   - JS 迁移函数支持（`Migration.migrate(db)`）
   - 迁移逻辑：保险 accounts → policies、删除信用卡、子账户提升、空父账户删除、系统钱包自动创建

2. **服务层新增/修改**
   - `insurance-service.ts`：保单 CRUD + 保费缴纳（事务：保费记录 + 银行扣款 + 流水账）
   - `account-service.ts`：四层架构 `getAllAssetsSummary()`、`listByBankName()`、`listBankAccounts()`
   - `account-transaction-service.ts`：`importWalletBills()` 双写（transactions + ledgers）
   - `ledger-service.ts`：`listLedgers()` 支持 `accountId` 过滤
   - `AccountRow` 新增 `display_alias` 字段

3. **IPC 层新增**
   - `insurance-ipc.ts`：9 个频道（保单 CRUD + 保费 + 查询）
   - `wallet-ipc.ts`：4 个频道（系统钱包 + 账单导入 + 银行列表）
   - `asset-ipc.ts`：新增 `asset:listByAccount` 频道

4. **前端页面**
   - **Accounts.tsx 完全重写**：Layer 2 卡片布局 + 统计卡片 + 银行分组可展开
   - **WalletFlow.tsx 新建**：钱包流水页（/wallet/:type）
   - **Insurance.tsx 新建**：保单管理页（/insurance）
   - **AccountDetail.tsx 增强**：银行理财产品卡片
   - **HoldingsDetail.tsx**：交易记录改为 SlidePanel 侧边滑出
   - **Dashboard.tsx**：饼图新增 e_wallet 分类（图标 + 颜色）
   - **App.tsx**：新增 /wallet/:type 和 /insurance 路由

5. **SlidePanel 组件**
   - 新建 `SlidePanel.tsx` + `SlidePanel.css`
   - 右侧滑入动画、Escape 关闭、点击遮罩关闭

6. **定时任务**
