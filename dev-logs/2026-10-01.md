# 2026-10-01 开发日志

## v1.10.21 报表跨账户合并 + 股票派息（股息）完整流程

### 背景

用户提出两件事：① 报表分析里同一只股票在不同账户的买卖不需要分开统计；② 股票派息没有完整记录流程。方案经确认（合并行+可展开各账户明细 / 不摊薄成本价 / 手工登记+日结单自动识别 / 同步记账+报表总收益），随后执行。

### 完成事项

1. **跨账户合并统计**：`mergeKey(code, currency)` + `computeRealizedPnl` 改为跨账户合并重放（附各账户独立口径明细）；`getDailyTrades` 重放键同步；report:realizedPnl SQL 关联 investment_accounts 取账户名；RealizedPnlCard 支持展开；投资收益明细/当日成交新增账户列
2. **股息完整流程**：新增 `dividend-service`（登记/修改/删除/按账户列表/银行股息补记）+ 4 个 IPC 频道；迁移 v26 给 ledgers 加 source_type/source_id；三个登记入口 + DividendFormModal；交易记录里股息行只读方向、删除走专用通道
3. **日结单识别**：normalizeTradeType 支持 dividend；券商日结单股息行导入即完整落库（交易+现金+记账）；银行日结单股息行预览提示并在导入时补记账；修复 `type='other'` 违反 CHECK 约束导致导入报错的老 bug
4. **报表**：新增「💰 股息收入」卡（税前/税/实收/笔数，按标的跨账户合并）；年度已实现盈亏卡新增「总收益 = 价差 + 股息」
5. **可测试性修复**：settings-ipc 中 11 处注册期 `require()`（项目 TS 模块）改为静态 import，使 IPC 注册可在 vitest 中直接跑通
