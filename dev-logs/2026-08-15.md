# 2026-08-15 开发日志

## 完成事项

### v1.5.2 报表功能增强

1. **每日交易报表**
   - 新增 `report-export-service.ts`：`getDailyTrades(date)` 按日查询交易（JOIN 持仓名称/代码），统计买入/卖出笔数金额 + 已实现盈亏（卖出净额 − 成本价×数量）
   - 新增 IPC：`report:dailyTrades`（查日报）、`export:dailyTrades`（导出当日 Excel：汇总 + 明细双 sheet）
   - 新建 `DailyTradesReport.tsx` 组件：日期选择（默认今天）+ 统计卡片 + 交易明细表 + 一键导出
   - `scheduler.ts`：新增 `scheduleDailyTradeReportCheck()` 每日 16:35 检查（港股 16:00 收盘后），有交易时推送 Windows 通知

2. **完整资产汇总导出**
   - `export:toExcel` 的 assets 类型升级为 7 sheet 完整快照：总览 / 银行账户 / 电子钱包 / 券商账户 / 投资持仓 / 定期存款 / 保险
   - 全部金额按 `rate_to_base` 换算为 CNY 等值；卡号脱敏为尾号后 4 位
   - Reports 页资产汇总导出隐藏月份/年份选择器（导出当前全部资产，无需时间筛选）
   - trades/ledgers 导出改用共享 `transformRows`/`getExportHeaders`

3. **统一持仓排序**
   - `asset-service.ts` 新增共享常量 `ASSET_SORT_SQL`：港股股票 → A股股票 → 美股股票 → 其他股票 → ETF → 基金 → 黄金 → 加密货币 → 定期存款，组内按代码升序
   - ⚠️ 修正：排序基于 `market` 列（hk_stock/a_stock/us_stock）+ `type` 列（stock/fund/etf/...），并非全部在 `type` 上
   - 应用于：`listAssets()`、`getAccountHoldings()`、`report:assetPerformance`、资产汇总导出的持仓 sheet
   - 已用真实数据验证：港股（00388/00981/02331/02800/09888）→ ETF（159218/159530/515880）
