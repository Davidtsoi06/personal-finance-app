## 📝 使用说明

1. 创建 GitHub 仓库
2. 修改 `electron-builder.yml`：将 `YOUR_GITHUB_USERNAME` 和 `YOUR_REPO_NAME` 替换为实际值
3. 创建 GitHub Personal Access Token（classic），勾选 `repo` 权限
4. 设置环境变量：`set GH_TOKEN=your_token_here`（Windows）
5. 运行 `npm run release` 发布版本
6. 用户打开软件 → 设置页面 → 检查更新 → 自动下载安装
