# 2026-08-09 开发日志

## ✅ 已完成事项

### 账户管理模块重构（Migration v7 + 树形 UI + 多币种）
- **Migration v7** — [src/main/database/migrations.ts](src/main/database/migrations.ts):
  - `ALTER TABLE accounts ADD COLUMN parent_account_id` — 支持银行→子账户层级
  - `CREATE TABLE account_balances` — 多币种余额表，UNIQUE(account_id, currency)
  - 数据迁移：`INSERT OR IGNORE INTO account_balances` 从现有 accounts.balance
- **account-service.ts 增强**:
  - `listAccountsAsTree()` — 返回完整树形结构（含 children + balances）
  - `getAccountWithTree(id)` — 单账户树形查询
  - `deleteAccount()` 返回 `DeleteResult` — 级联检查（子账户/ledgers/transactions/assets）
  - `getAccountBalances()` / `updateAccountBalance()` — 多币种余额增删改
  - `createAccount()` 支持 `parent_account_id`，自动创建 account_balances
  - `getTotalBalance()` 支持按币种过滤
- **account-transaction-service.ts** — 存取操作同步 account_balances
- **ledger-service.ts** — 收支操作同步 account_balances（create/update/delete 三处）
- **account-ipc.ts** — 新增 `account:listTree` / `account:balances` / 增强 `account:get` / `account:delete`
- **Accounts.tsx 重写**:
  - 树形列表：递归渲染，缩进 28px/级，父级📁子级按类型图标
  - 行内操作：✏️ 编辑 / 🗑 删除按钮（e.stopPropagation）
  - 编辑 Modal：AccountForm 复用组件，支持修改名称/类型/币种/余额/银行/卡号/父账户
  - 删除 Modal：显示 DeleteResult 错误信息（子账户/关联交易提示）
  - 点击行跳转 AccountDetail（仅叶子节点）
- **Accounts.css** — 树形行样式、hover、余额对齐、操作按钮区
- **AccountDetail.tsx** — 新增多币种余额卡片（💱 多币种余额），显示各币种余额

### 投资当日盈亏统计
- **investment-account-service.ts** — 新增 `getDailyTradeStats()`:
  - 今日买入笔数 / 卖出笔数
  - 已实现盈亏 = Σ(total_amount - cost_price × quantity) for today's sells
- **settings-ipc.ts** — 新增 `investmentAccount:dailyStats` handler
- **Investments.tsx** — 新增当日统计卡片行（📈买入 / 📉卖出 / 💰已实现盈亏）

### 股价更新增强
- **price-fetcher.ts 全面重写**:
  - 所有 5 个 fetch 函数增加结构化 `console.error` 日志（HTTP 状态码/返回格式/解析失败）
  - 美股增加新浪财经备选数据源（`gb_` 前缀），Yahoo 失败后自动降级
  - `fetchAllPrices()` 增加运行日志（开始/完成/错误摘要）
  - 未知市场类型不再静默失败

### AI 每日投资总结
- **portfolio-context.ts** — 新增 `generateDailySummaryContext(date)`:
  - 当日交易明细 / 当前持仓快照 / 净资产变化（日环比）/ 本月收支概况
- **ai-service.ts** — 新增 `generateInvestmentSummary(date?)`:
  - 专用 System Prompt（300-500字日报，包含交易概况/持仓表现/分析与建议）
  - 调用现有 `chat()` 方法
- **settings-service.ts** — 新增 `getDailySummary()` / `saveDailySummary()`（基于 app_settings KV）
- **settings-ipc.ts** — 新增 `ai:dailySummary` handler（先查缓存，无则生成）
- **scheduler.ts** — 新增 15:33 定时任务 `scheduleDailyAISummary()`（收盘后自动生成+通知）
- **AIAssistant.tsx** — 新增「📋 今日投资日报」快捷提示按钮（特殊处理，调用 ai:dailySummary）

### 一键数据清零
